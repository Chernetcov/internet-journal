# AGENTS.md

## 1. О проекте

«Культурный код» — авторский философский и культурный журнал на русском языке.

Основные темы издания:

- Философия
- Литература
- Искусство
- Кинематограф

Сайт предназначен для публикации авторских статей, эссе, рецензий, интервью и аналитических материалов.

Основная задача проекта — создать современное цифровое культурное медиа с качественной типографикой, удобным чтением и 
выразительным редакционным дизайном.

## 2. Технологический стек

- Backend: Python, Django 5.
- Frontend: Django Templates.
- CSS: Tailwind CSS, связь с Django при помощи django_tailwind_cli
- Database: PostgreSQL.
- JavaScript: Vanilla JavaScript, если нет необходимости использовать дополнительные библиотеки.
- Django Admin: интерфейс управления публикациями и редакционным контентом. Для возможности ввода html использован django_ckeditor_5

## 4. Запреты 

- нельзя использовать команды git
- нельзя добавлять какие-либо frontend-фреймфорки
- нельзя устанавливать зависимости Django, только предлагать
- нельзя обновлять версии уже установленных зависимостей
- нельзя менять существующую архитектуру


## 5. Как запускать

Команды для создания миграций
> python manage.py makemigrations iju 
> python manage.py migrate

Команда для запуска локального сервера:
> python manage.py tailwind runserver

## 6. Тестирование

Тесты надо писать только если в промпте прямо указано "напиши тест"
Тесты надо запускать только если в промпте прямо указано "запусти тест"
