# Интернет журнал

Рабочее название "Культурный код"

## Концепция

Планируется этакий расширенный блог, в который будет писать редактор (в основном) + близкие авторы.
Админка для авторов пока не планируется
На начальном этапе надо построить каркас сайта и проверить идею: интересно ли это кому-нибудь
Планируется выпускать 1-2 статьи в неделю в течение первых 3 месяцев.

## Запуск

Команды для создания миграций
> python manage.py makemigrations iju 
> python manage.py migrate

Команда для запуска локального сервера:
> python manage.py tailwind runserver

##  Примечания

### MEDIA_ROOT при запуске на localhost c DEBUG=False 
При запуске на localhost в режиме DEBUG=False изображения не отображаются, т.к. whitenoise возвращает только 
статичные файл, а не содержимое MEDIA_ROOT. Чтобы возвращать содержимое MEDIA_ROOT надо добавить запись типа:
```python
if not settings.DEBUG:
    urlpatterns += [
        path(
            f"{settings.MEDIA_URL.lstrip('/')}<path:path>",
            serve,
            {'document_root': settings.MEDIA_ROOT},
        ),
    ]
```
но это повлияет на запуск в production, поэтому такая запись не добавлена.
